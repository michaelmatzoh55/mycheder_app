# My Cheder

A Jewish learning app for kids, Nusach Chabad: davening, the Alef-Beis, the weekly parsha with Rashi, Chassidus, Chitas, mitzvos, Chanukah and more.

Live at https://mycheder-app.vercel.app

This is a plain static website (no build step). Vercel serves the files as they are.

Updates go live automatically: every push to `main` is deployed by Vercel.
